# Five minutes: follow one intent into the shipped package

**Audience:** SPFx and M365 engineers. Start in the sample directory with the [local studio](README.md#review-it-locally) and current [release evidence](assets/release-evidence.json). Reset; use the rehearsal lead and the fixed commercial cut from the [keynote](Employee-Hub-3-Minute-Demo.md).

| Time | Show | Verify |
|---|---|---|
| 0:00-1:00 | Ask **“How many partner leads in Germany became opportunities this quarter?”** Expected `TraceLeadConversion`, `{marketId:"DE",period:"current-quarter",channel:"partner"}`. Open the [canonical row](config/hub-catalog.json) and [input normalization](src/hosts/fields.ts). | The support-flow component owns IT queues, not sales leads. Every argument is optional; a prompt cannot supply `confirm` or a role. |
| 1:00-2:00 | Change channel and inspect the [lead renderer](src/shared/business/LeadReview.tsx) and [commercial cuts](src/shared/mockData/commercial.ts). Follow the safe public count through the [bridge](src/hosts/bridge.ts). | Name the numerator, denominator and cut. A selection updates context, not chat. **Discuss this view** is an explicit user action. A failed context publication must not send a follow-up. |
| 2:00-3:00 | Expand. Compare the [Copilot adapter](src/hosts/HubCopilotComponent.tsx) with the [web-part adapter](src/hosts/HubWebPart.tsx). Inspect [HostFrame](src/hosts/HostFrame.tsx). | Host mode controls expansion. A same-instance change of inputs starts a new draft but retains confirmed fixture state. Another instance or signed-in identity starts clean. SharePoint never sends Copilot chat. |
| 3:00-4:00 | Open the [package audit](release/host-package-audit.json) and [compiled-entry evidence](review/evidence/compiled-host.json). Show the four full-page declarations, five Teams component IDs, one embedded agent and [hand-authored Cowork manifest](employee-hub-plugin/manifest.json). | 30 single-tool entries and 34 web-part exports. Cowork dynamically resolves the same solution; neither its ZIP nor a Teams workspace includes a duplicate tool catalog. |
| 4:00-5:00 | Ask **“How much annual leave is available?”** → `CheckLeaveBalance` (#14, `leaveType=annual`); switch year. **“How do I reconnect my second screen?”** → `FindTroubleshootingGuide` (#21); advance a step. Open the [host-frame regressions](scripts/host-frame.test.cjs) and compare with the [install gates](docs/pilot-install.md). | The safe context changes to the visible year or step without sharing the balance or any note. A zero-error compiled harness is not a signed-in routing trace. |

**Fallback and checklist:** run `npm run review:candidate` before the meeting; match the `.sppkg` fingerprint, reset the overlay, and keep the [local walkthrough](review/evidence/commercial-rehearsal.webm) available. If model routing or a host fails, record the prompt and outcome, switch to the named local renderer and say what the fallback does not test.
