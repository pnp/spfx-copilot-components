# Three minutes: from a bookings gap to one decision

**Audience:** senior leadership. **Question:** where should we spend the next review, and what evidence will the owner revisit? Start the [studio](README.md#review-it-locally) with the rehearsal lead, light theme and clock `2026-11-27T09:00:00Z`. Reset the session. In an authorized Copilot host ask the quoted prompts. In the studio select those entries yourself and say so.

| Time | Show and say |
|---|---|
| 0:00-0:40 | Ask **“Which countries are furthest below bookings plan?”** Expect only `MapSalesMarkets` (#03), inline. Select Germany: $3.2m booked versus $4.8m phased plan, a $1.6m shortfall. This map measures historical actuals, not the quarter-end estimate. |
| 0:40-1:25 | Ask **“How many partner leads in Germany became opportunities this quarter?”** Expect only `TraceLeadConversion` (#09), `marketId=DE`, `channel=partner`, `period=current-quarter`. Read **8 of 60**. Switch to Inbound: **12 of 40**. They are different populations, not a before/after improvement. Switch back to Partner. |
| 1:25-2:05 | Select **Qualified → Opportunity created** with the keyboard, then **Expand**. Stay on `business/leads`. The partner selection remains while the wider view adds the inbound comparison and exact counts. Discuss the evidence without opening another tool. |
| 2:05-3:00 | Choose **Prepare an investigation** (#06, an explicit handoff). Select an accountable role and review checkpoint. Open **Review action**; show that **Record session action** is disabled. Check the confirmation, then record once. The original 8/60 citation remains with the receipt. No CRM assignment was sent and no bookings changed. |
