# Sample gallery and image provenance

`sample.json` describes this sample for the repository gallery. Its thumbnail, `overview.svg`, is an original architecture illustration included under the repository's [MIT license](../../../LICENSE). It is a diagram of the request and action flow, rather than a screenshot of the Copilot host.

The component bundles eight fictional portraits locally. Their [provenance](../src/copilot-expert-finder/src/copilotComponents/expertFinder/assets/README.md) records AI generation for this project, with no real-person reference photographs or third-party stock images. No remote portrait host is used at runtime. The UI logo and agent icons remain with the SPFx source assets.

Future UI screenshots should use fictional profiles or authorized, anonymized test data. Keep them local to this folder and reference gallery images in `sample.json`.
