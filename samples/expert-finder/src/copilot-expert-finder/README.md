# Expert Finder SPFx project

This directory contains the buildable SharePoint Framework 1.24.1 project. Start with the [sample README](../../README.md) for prerequisites, features, data-source behavior and installation.

Use Node.js 24.x. Run these commands from this directory:

```bash
npm install
npm start -- --nobrowser
```

Stop the development server before building:

```bash
npm run build
```

The build produces `sharepoint/solution/copilot-expert-finder.sppkg`. See [deployment](../../docs/deployment.md) for Copilot Workbench, the App Catalog and agent synchronization.
