# Fictional profile portraits

The eight PNG portraits were generated with OpenAI image generation on November 3, 2026 specifically for this project. The prompts requested fictional adults, professional business-casual headshots, plain neutral backgrounds, and no text or logos. No reference photograph of a real person was supplied, and no third-party stock photographs were used.

Files: `alex.png`, `sam.png`, `jamie.png`, `priya.png`, `daniel.png`, `noor.png`, `leo.png`, `elena.png`. The copies are bundled as local SPFx assets, with no external image-host dependency. Names, professional summaries and identities in the mock data are fictional. A person can have separate records for different skills.

These generated portraits are distributed with the sample under the repository license. See [sample image provenance](../../../../../../assets/README.md) for gallery assets and the license link.
