One card / Several purposeful stages

A short turn keeps the experience in context. Try one-to-many-to-one learning, or compose, review and confirm a praise preview. Back reverses the transition; reduced motion uses an instant swap.

CARD STAGE / SHARED PATTERN FOR THE NEXT UX PASSReview only / No training launch or praise submission

C13 / Read flow
One next-required course - all three - a selected course - back.

C14 / Write flow
Send praise - compose - review - confirm preview. Edit keeps the draft.

Shared, not forced. All 34 capabilities inherit this stage-navigation language for the next UX pass. Use only relevant stages. A card flip never submits data; source receipts, errors and safe retries remain explicit. Large tasks may expand. Native Dashboard cards use supported Quick Views or destinations.

Motion inspiration: React Bits Flip Card. No code copied or dependency selected. This review uses an original 240ms card-body turn, one active face, keyboard focus return and a reduced-motion alternative.
